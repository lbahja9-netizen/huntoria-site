## Example Lesson Plan Structure

### UK Example — Year 2 Maths (Monday)
**WALT:** We are learning to add two 2-digit numbers
**WILF:** I can use a number line to add and write the correct answer

| Time | Activity | Notes |
|------|----------|-------|
| 9:00–9:05 | Starter: Counting in 2s | Choral counting |
| 9:05–9:15 | I do: Model adding on number line | Interactive whiteboard |
| 9:15–9:25 | We do: Guided practice | Mini-whiteboards |
| 9:25–9:40 | You do: Independent activity | Differentiated worksheets |
| 9:40–9:45 | Plenary: Exit ticket | 3 questions |

**Differentiation:**
- SEN: Numicon resources, adult support
- EAL: Visual number line, partner work
- Higher: Challenge card — add 3 numbers

---

### US Example — Grade 3 ELA (Monday)
**I can:** Retell a story, including key details, and demonstrate understanding of the central message

| Time | Activity | Notes |
|------|----------|-------|
| 9:00–9:10 | Morning Meeting / Warm-Up | Vocabulary preview |
| 9:10–9:20 | Mini-Lesson: Story elements | Read-aloud |
| 9:20–9:35 | Guided Practice: Shared reading | Think-aloud |
| 9:35–9:50 | Independent Reading | Reading response journal |
| 9:50–9:55 | Share & Closure | Partner share |

**Differentiation:**
- ELL: Picture supports, sentence frames
- Struggling readers: Paired reading, simplified text
- Advanced: Compare two stories, written response
