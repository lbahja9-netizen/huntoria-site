# Year 5 Weekly Lesson Plan — Fractions, Decimals & Percentages
## British National Curriculum (UK)

**Week:** 22–26 September 2025
**Year Group:** Year 5 (Ages 9–10)
**Subject:** Mathematics — Fractions (including decimals and percentages)
**Class Size:** 30 students

---

## Curriculum Objectives (National Curriculum for England)

Pupils should be taught to:
- Compare and order fractions whose denominators are all multiples of the same number
- Identify, name and write equivalent fractions of a given fraction, represented visually, including tenths and hundredths
- Recognise mixed numbers and improper fractions and convert from one form to the other
- Add and subtract fractions with the same denominator and denominators that are multiples of the same number
- Multiply proper fractions and mixed numbers by whole numbers, supported by materials and diagrams
- Read and write decimal numbers as fractions
- Recognise and use thousandths and relate them to tenths, hundredths and decimal equivalents
- Recognise the per cent symbol (%) and understand that per cent relates to 'number of parts per 100'

---

## Key Vocabulary
fraction, numerator, denominator, equivalent, improper, mixed number, decimal, tenths, hundredths, thousandths, percentage, per cent, convert, simplify

## Monday — Equivalent Fractions

**WALT:** We are learning to identify and write equivalent fractions
**WILF:** I can find equivalent fractions using multiplication and division

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:05 | Starter | Quick-fire: What is 1/2 of 24? 3/4 of 20? 2/5 of 30? |
| 9:05–9:15 | I Do | Model finding equivalent fractions using fraction walls and bar models (e.g. 1/2 = 2/4 = 4/8) |
| 9:15–9:25 | We Do | Guided practice — pupils use multiplication tables to find missing numerators (e.g. 3/5 = ?/20) |
| 9:25–9:40 | You Do | Differentiated worksheets: Set A (×2, ×5, ×10 only), Set B (×2–×12), Set C (challenge — find all equivalents for 1/3 up to denominator 30) |
| 9:40–9:45 | Plenary | Exit ticket: Write 3 equivalent fractions for 3/4 |

**Differentiation:**
- **SEN:** Use fraction wall printed resource, work with adult support
- **EAL:** Visual fraction strips, key vocabulary mat provided
- **Higher:** Challenge — how many equivalent fractions can you find for 2/3 between 1/3 and 1?

**Resources:** Fraction walls, bar model templates, differentiated worksheets, mini-whiteboards

**Video Support:** [Equivalent Fractions — Corbettmaths](https://www.youtube.com/watch?v=mTY6qa6GhQo)

## Tuesday — Comparing and Ordering Fractions

**WALT:** We are learning to compare and order fractions
**WILF:** I can use common denominators to compare two fractions

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:05 | Starter | Which is bigger: 2/5 or 3/7? Discuss with partner |
| 9:05–9:15 | I Do | Model comparing fractions using equivalent fractions to make common denominators |
| 9:15–9:25 | We Do | Whole class — order 1/3, 2/5, 3/4 on a number line |
| 9:25–9:40 | You Do | worksheets: compare pairs of fractions, order 4 fractions from smallest to largest |
| 9:40–9:45 | Plenary | Reasoning question: Ammar says 4/9 is bigger than 1/2 because 4 > 1. Is he correct? Explain. |

**Differentiation:**
- **SEN:** Use shaded fraction cards for visual comparison
- **EAL:** Sentence starters: "_____ is bigger/smaller than _____ because..."
- **Higher:** Compare three fractions and place on a number line

**Resources:** Fraction cards, number line poster, reasoning question slides

## Wednesday — Adding and Subtracting Fractions

**WALT:** We are learning to add and subtract fractions with the same denominator
**WILF:** I can add/subtract fractions and simplify the answer

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:05 | Starter | Mental: 3/7 + 2/7 = ? 5/9 - 2/9 = ? (mini-whiteboards) |
| 9:05–9:15 | I Do | Model adding fractions with same denominators, then show converting to common denominators for different denominators |
| 9:15–9:25 | We Do | Worked examples: 2/3 + 1/6, 3/4 - 1/3 (find LCD) |
| 9:25–9:40 | You Do | Progressive worksheet: Start with same denominators, move to different denominators |
| 9:40–9:45 | Plenary | Word problem: "I ate 2/5 of a pizza. My friend ate 1/3. How much did we eat altogether?" |

**Differentiation:**
- **SEN:** Focus on same-denominator problems only, use visual models
- **EAL:** Key phrase card: "First I find the common denominator, then I add/subtract the numerators"
- **Higher:** Challenge — 5/6 - 2/3 + 1/4 = ? (three fractions, different denominators)

**Resources:** LCD method poster, visual fraction models, word problem cards

**Video Support:** [Adding Fractions — Corbettmaths](https://www.youtube.com/watch?v=mTY6qa6GhQo)

## Thursday — Fractions, Decimals and Percentages

**WALT:** We are learning to convert between fractions, decimals and percentages
**WILF:** I can convert any fraction to a decimal and percentage

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:05 | Starter | Quick conversions: 1/2 = ?%, 1/4 = ?%, 3/4 = ?% (known facts) |
| 9:05–9:15 | I Do | Model converting fractions to decimals (divide numerator by denominator), decimals to percentages (×100) |
| 9:15–9:25 | We Do | Converting triangles: complete conversion triangles for 1/2, 1/4, 3/4, 1/5, 2/5, 3/5 |
| 9:25–9:40 | You Do | Conversion matching activity — match fraction cards to decimal cards to percentage cards |
| 9:40–9:45 | Plenary | Real-world problem: A shop has 30% off. That's the same as which fraction? Which decimal? |

**Differentiation:**
- **SEN:** Focus on key facts (1/2, 1/4, 3/4) with visual support
- **EAL:** Conversion reference card provided
- **Higher:** Include thousandths (3/8 = 0.375 = 37.5%)

**Resources:** Conversion triangle templates, matching card sets, real-world problem cards

**Video Support:** [Decimals as Fractions — Twinkl Video](https://www.twinkl.com/resource/year-5-decimals-as-fractions-video-lesson-t-m-33974)

## Friday — Problem Solving & Reasoning

**WALT:** We are learning to solve problems involving fractions, decimals and percentages
**WILF:** I can explain my reasoning clearly using mathematical vocabulary

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:05 | Starter | Flash card round — quick conversions and comparisons |
| 9:05–9:20 | I Do | Model a multi-step word problem (e.g. measuring problem involving fractions of litres) |
| 9:20–9:40 | You Do | Carousel of challenges: Problem-solving cards, investigation (Which is closest to 1/2: 3/7, 4/9, or 5/11?), mini-project (plan a party using fractions of a budget) |
| 9:40–9:50 | Plenary | Peer assessment — swap work, mark with green pen, give one star and one wish |

**Differentiation:**
- **SEN:** Pre-teach vocabulary, provide scaffolded problem frames
- **EAL:** Visual problem cards with pictures, sentence starters for explanations
- **Higher:** Create your own word problem for a partner to solve

**Resources:** Problem-solving challenge cards, investigation recording sheet, party budget template
