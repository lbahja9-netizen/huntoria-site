## What Teachers Get

Each weekly lesson plan includes:
- **5-day lesson plan** (Mon–Fri)
- **Daily breakdowns** with WALT/WILF (UK) or I Can statements (US)
- **Time-stamped activities** (starter, main, plenary)
- **Differentiation** for SEN, EAL/ELL, and higher attainers
- **Resources list** for each day
- **Video links** for teacher reference and student support
- **Assessment** plan (formative + summative)
- **Cross-reference** to curriculum standards
