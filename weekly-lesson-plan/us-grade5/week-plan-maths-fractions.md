# 5th Grade Weekly Lesson Plan — Adding & Subtracting Fractions/Decimals
## American Common Core Curriculum (US)

**Week:** September 22–26, 2025
**Grade:** 5th Grade (Ages 10–11)
**Subject:** Mathematics — Number & Operations: Fractions (5.NF) and Number & Operations in Base Ten (5.NBT)
**Class Size:** 28 students

---

## Common Core State Standards

**5.NF.A.1** — Add and subtract fractions with unlike denominators (including mixed numbers) by replacing given fractions with equivalent fractions

**5.NF.A.2** — Solve word problems involving addition and subtraction of fractions referring to the same whole, including cases of unlike denominators, using benchmark fractions and number sense to estimate and assess reasonableness

**5.NBT.B.7** — Add, subtract, multiply, and divide decimals to hundredths, using concrete models or drawings and strategies based on place value

---

## Learning Targets (I Can Statements)

- I can add fractions with unlike denominators by finding a common denominator
- I can subtract fractions with unlike denominators
- I can add and subtract decimals to the hundredths place
- I can solve word problems involving fractions and decimals
- I can use benchmark fractions to estimate and check my answers

---

## Key Vocabulary
fraction, numerator, denominator, unlike denominators, like denominators, common denominator, least common multiple (LCM), equivalent fraction, mixed number, improper fraction, decimal, hundredths, place value, sum, difference, estimate, reasonableness

## Monday — Adding Fractions with Unlike Denominators

**I Can:** Add fractions with unlike denominators by finding a common denominator

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:08 | Warm-Up | Number talk: "Why can't we add 1/3 + 1/4 the way we add 1/3 + 2/3?" Think-Pair-Share |
| 9:08–9:18 | I Do (Mini-Lesson) | Model finding the LCD using multiplication and the LCM method. Show 1/3 + 1/4 = 4/12 + 3/12 = 7/12 using area models |
| 9:18–9:30 | We Do (Guided Practice) | Partner work: Solve 3 problems together using fraction strips and area models. Teacher circulates |
| 9:30–9:48 | You Do (Independent) | "Fractions Addition" worksheet — 8 problems with visual models. Finish early? Try the challenge problem |
| 9:48–9:55 | Closure | Exit ticket: 2/5 + 1/3 = ? Show your work |

**Differentiation:**
- **ELL/MLL:** Vocabulary reference card with pictures, sentence frame: "The common denominator is ___ because..."
- **Struggling:** Use fraction strips for all problems, reduce to 5 problems
- **Advanced:** Create your own word problem that requires adding fractions with unlike denominators

**Resources:** Fraction strips, area model paper, exit tickets, anchor chart

**Video Support:** [Khan Academy — Adding Fractions with Unlike Denominators](https://www.khanacademy.org/math/cc-fifth-grade-math/imp-fractions-3/imp-adding-fractions/v/adding-fractions-with-unlike-denominators)

## Tuesday — Subtracting Fractions with Unlike Denominators

**I Can:** Subtract fractions with unlike denominators and convert answers to mixed numbers when needed

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:08 | Warm-Up | Quick check: 3/4 - 1/4 = ? 5/6 - 2/6 = ? 1 - 3/5 = ? (same denominator review) |
| 9:08–9:18 | I Do | Model subtraction with unlike denominators: 3/4 - 1/3. Show converting improper fractions to mixed numbers |
| 9:18–9:30 | We Do | Solve 4 subtraction problems as a class. Use number lines for visual support |
| 9:30–9:48 | You Do | Differentiated worksheets: Set A (simple subtraction), Set B (includes mixed numbers), Set C (word problems) |
| 9:48–9:55 | Closure | Gallery walk — students post their work, classmates leave sticky note feedback |

**Differentiation:**
- **ELL/MLL:** Visual anchor chart showing subtraction steps, partner support
- **Struggling:** Focus on problems where LCD is a multiple of both denominators
- **Advanced:** Solve 5/6 - 2/3 + 1/4 (three fractions, different denominators)

**Resources:** Number line poster, differentiated worksheets, sticky notes, anchor chart

## Wednesday — Adding and Subtracting Decimals

**I Can:** Add and subtract decimals to the hundredths place using place value understanding

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:08 | Warm-Up | Money connection: "If you have $4.25 and spend $1.75, how much is left?" Mental math |
| 9:08–9:18 | I Do | Model decimal addition/subtraction using money and base-10 blocks. Emphasize lining up decimal points and place value |
| 9:18–9:30 | We Do | Guided practice: 3.45 + 2.78, 6.3 - 2.47 using place value charts and standard algorithm |
| 9:30–9:48 | You Do | Decimal operations worksheet. Include money word problems and measurement problems |
| 9:48–9:55 | Closure | Error analysis: Find and fix the mistake in 4.5 + 3.27 = 7.77 |

**Differentiation:**
- **ELL/MLL:** Place value chart with labels, real-world money contexts
- **Struggling:** Use base-10 blocks for concrete support, start with tenths only
- **Advanced:** Subtract decimals that require regrouping across zeros: 10.00 - 3.45

**Resources:** Base-10 blocks, place value charts, money manipulatives, error analysis cards

**Video Support:** [LearnZillion — Adding and Subtracting Decimals](https://learnzillion.com/lesson_plans/8889-add-and-subtract-decimals-to-the-hundredths-place-using-place-value-understanding/)

## Thursday — Fractions and Decimals: Converting

**I Can:** Convert between fractions and decimals and understand their equivalence

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:08 | Warm-Up | "What is 1/2 as a decimal? As a percentage? What about 1/4? 3/4?" Quick-fire |
| 9:08–9:18 | I Do | Model converting fractions to decimals (divide numerator by denominator) and decimals to fractions (place value). Use benchmark fractions |
| 9:18–9:30 | We Do | Converting matching game — students match fraction cards to decimal cards on the floor |
| 9:30–9:48 | You Do | Conversion worksheet: fractions to decimals, decimals to fractions, mixed numbers. Include thousandths |
| 9:48–9:55 | Closure | Reflection journal: "Explain to a 4th grader how to convert 3/4 to a decimal" |

**Differentiation:**
- **ELL/MLL:** Visual conversion chart, sentence frames for journal
- **Struggling:** Focus on benchmark fractions (1/2, 1/4, 3/4, 1/5)
- **Advanced:** Include repeating decimals (1/3 = 0.333...)

**Resources:** Conversion reference chart, matching card game, journal prompt cards

**Video Support:** [Math Antics — Converting Fractions to Decimals](https://www.youtube.com/watch?v=GnW1JUo9Gs8)

## Friday — Word Problems and Assessment

**I Can:** Solve multi-step word problems involving fractions and decimals

| Time | Activity | Details |
|------|----------|---------|
| 9:00–9:08 | Warm-Up | Estimation challenge: "Estimate the answer before calculating" — 3 problems |
| 9:08–9:20 | I Do | Model solving a multi-step word problem: "Maria has 3/4 cup of sugar. She uses 1/3 cup for the cake and 1/4 cup for the frosting. How much sugar is left?" |
| 9:20–9:40 | You Do | Word problem workshop: 6 problems of increasing difficulty. Students work independently, then compare strategies with a partner |
| 9:40–9:50 | Assessment | Exit ticket quiz: 5 problems covering all week's skills (adding/subtracting fractions, decimals, conversions) |
| 9:50–9:55 | Closure | "One thing I learned this week" — share with partner |

**Differentiation:**
- **ELL/MLL:** Word problems with visual models, key vocabulary highlighted
- **Struggling:** Provide sentence starters for word problems, allow calculator for checking
- **Advanced:** Create a multi-step word problem that uses at least 3 different skills from this week

**Resources:** Word problem cards, exit ticket quiz, partner discussion prompts
